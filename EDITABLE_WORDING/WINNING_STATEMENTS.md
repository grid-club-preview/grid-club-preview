# Grid Club — Winning Statements

Editable reference list, extracted from v0.9.2. The running app uses `win-messages.js` from v0.9.3 onward.

You can add/edit phrases in this document and send back your revisions. To publish changes without another code update, edit the matching strings in `win-messages.js` (in the public website files), then upload that updated file to GitHub. Changes in Google Drive alone do not affect the live website.
