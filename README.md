# Grid Club web prototype v0.3

**Dot Trails:** connect matching dots, fill the board, and keep the lines separate.

Free Play: 5×5, 7×7, 9×9, 11×11. Daily puzzle: fixed 11×11.

Open `index.html` in Chrome to try it. See `PUBLISH_FROM_WINDOWS.md` for replacing the previous version on GitHub Pages and adding the site to an iPhone Home Screen.

The puzzle engine (`puzzle.js`) is plain JavaScript; automated checks: `node tests/engine.test.js`.

This is a free prototype, not an App Store submission.
